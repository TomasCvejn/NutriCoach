# Onboarding & client profile

## Onboarding (first login after accepting the invite)
Step-by-step with progress indicator and back/next; each step is saved, so a refresh doesn't lose answers.
1. Welcome — coach's name and welcome text (coach edits it in settings).
2. Personalization questions — the profile sections below (personal info, dietary info, training/sport, preferences, additional info) plus preferred tracking style (calories / portions / guidance, each explained; the coach decides the final mode unless the invite already set it).
3. Goal selection — primary goal: lose fat / maintain / gain muscle / performance / health & energy / competition preparation; optional target weight and date; free text "what does success look like?".
4. Done → client home. Coach gets a notification "onboarding completed".

## Client profile (client edits own; coach sees and edits)
One page with sections, same fields as onboarding:
- Personal information: name, sex, birth date, height (cm), current weight (kg), phone (optional).
- Goals: primary goal, target weight/date, success text.
- Preferences: liked foods, disliked foods, meals per day.
- Dietary information: diet type (omnivore / pescatarian / vegetarian / vegan / other), allergies & intolerances (EU 14 allergens checkboxes + free text), other restrictions.
- Training/sport: sport(s) (a sport turns on the Training section, `00-overview.md`), level (recreational / amateur competitive / elite), sessions per week, typical session length.
- Additional info: health conditions, medications, anything else (free text).
Allergies and diet type drive recipe warnings (`recipes.md`).
